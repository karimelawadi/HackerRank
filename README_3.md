# Python Practice — Karim Elawadi

A personal collection of solved Python exercises and coding challenges, built while working toward a data science / machine learning role. Covers core language fundamentals through functional programming patterns.

## Contents

| Notebook | Topics Covered |
|---|---|
| `Python_Introduction.ipynb` | Hello World, arithmetic operators, division, if-else, loops, functions, formatted output |
| `Python_Basic_Data_Types.ipynb` | List operations, nested lists, tuples & hashing, runner-up scores, percentage/average calculations |
| `Python_Strings.ipynb` | Substring counting, case swapping, split & join, string validation, mutation, text wrapping, capitalization |
| `Python_Sets.ipynb` | Union, intersection, difference, symmetric difference, set mutations, subset/superset checks |
| `Python_Collections.ipynb` | `collections.Counter` for counting and inventory-style problems |
| `Python_Built-Ins.ipynb` | `zip()`, `eval()`, combining and evaluating input data |
| `Python_Functionals.ipynb` | Lambda functions with `map()`, Fibonacci sequence generation |
| `Python_Closures_and_Decorators.ipynb` | Building decorators (phone number formatting example) |
| `Python_Errors_and_Exceptions.ipynb` | `try`/`except` handling, regex validation with error handling |
| `Python_Regex_and_Parsing.ipynb` | Matrix-based string decoding using regular expressions |
| `Python_Math.ipynb` | `pow()`, `divmod()`, complex numbers, angle/coordinate calculations |
| `Assignamet-1.ipynb` | Merging & manually sorting two lists (no built-in sort), repeating string characters without `if` |
| `Assignment-2.ipynb` | Filtering products by price threshold, updating a salary dictionary from percentage increments |
| `Workshop.ipynb` | Lambda/comprehension practice — vowel counting, doubling lists, set operations, dict key/value swap, tuple mutation, palindrome check, occurrence counting, while-loop accumulation, duplicate removal, word-index mapping |

## Focus Areas

- **Core data structures**: lists, tuples, sets, dictionaries
- **String processing**: parsing, formatting, validation
- **Functional programming**: `lambda`, `map()`, `filter()`, list/dict comprehensions, immediately-invoked lambda expressions (IIFE pattern)
- **Control flow**: `for`/`while` loops, conditional expressions
- **Error handling**: `try`/`except` for robust input handling
- **Efficiency**: comparing brute-force vs. optimized approaches (e.g., `list` vs `set` lookups)

## Notes

Most solutions favor explicit, readable approaches over built-in shortcuts (e.g., manual sorting instead of `sorted()`) where the exercise specifically calls for it. Several exercises in `Workshop.ipynb` intentionally practice the `(lambda ...)(value)` immediately-invoked pattern inside comprehensions as a way to reinforce lambda syntax.

- Python 3.13
